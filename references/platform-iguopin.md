# 国聘（iguopin.com）

## 搜索页（免登录可抓）

- URL：`https://www.iguopin.com/job/list?keyword=<关键词>`
- 卡片：`.job-card`
- 切校招：JS 点「校招」文本（片段见 js-snippets），即使有遮罩也有效
- 翻页：点 `.ant-pagination-next`

抓取 JS 见 [js-snippets.md](js-snippets.md)「抓取-国聘卡片」。实测 20/20 拿到 `job_id`。

关键字段：`applied`（**2 = 未投递可用**，其他 = 已投/不可用）、
`recruitment_type_cn`（校招为「校园招聘」）、`education_cn`、`job_id`。

**抓取阶段就按 `applied` 过滤**，能一次排掉大量无效卡片。

## 详情页（**整页登录墙**）

`https://www.iguopin.com/job/detail?id=<job_id>`

未登录访问会直接跳登录页：正文只有两百来字，按钮是「微信登录 / 密码登录 / 短信验证码」。
**必须先登录**，否则投递链路根本进不去。

登录态判定：正文长度 < 500 且按钮里出现上述三个文案之一。

## 投递流程（登录后在单一页面内完成）

1. 导航到详情直链
2. 读 JD + 结构化字段，**立刻落盘**
3. JD 门禁判定 → 决定用哪份简历
4. 点「申请职位」
5. 弹窗里选简历
6. 点「**确认申请**」——注意文案是「确认申请」，不是「确认」

弹窗细节：

- 简历选择器是 `combobox "Resume id"` + `button "<简历名>"`，展开后 listbox 里有 `option "<简历名>"`
- 失败文案：「申请失败 / 简历数据不完整 / 完善简历」，点「完善简历」跳 `c.iguopin.com/apply?...`
- 「申请职位」按钮**必须轮询 + JS 兜底**（见 driver-bsk.md 第 7 条；chrome-devtools 下直接拿 uid 点）

## 集团投递上限

部分集团设「同一单位/项目最多投 N 个职位」（常见 1~6 个），常同时要求专属简历模板。
被拦截后**整组跳过**并加黑名单，不要反复消耗配额。同一集团的收藏职位要批量清掉。

**黑名单必须用工商全称或字号匹配**——列表展示的是全称，写简称命中为 0。
例如「中国联通」要展开成「中国联合网络通信有限公司XX分公司 / 联通数字科技 / 联通华盛通信 /
联通在线信息科技」。常见需要展开的：中国移动、中国电信、咪咕、中铝、国投、
国家电投（含绿能国际、山东核电等挂靠项目）、中远海运、中国旅游集团（中旅旅行 / 中旅国际 /
香港中旅 / 中旅好时光）、国机集团（中国机械工业集团 / 中国一拖）。

## 收藏

**只有「真失败」才收藏**（无确认按钮 / 仍缺信息 / 弹窗异常）。
专属模板、集团上限、此前已投、非目标岗位一律不收藏。收藏时排除已含「已收藏」文案的按钮。

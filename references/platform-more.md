## 实习僧 shixiseng.com（推荐）

校招 URL：`https://www.shixiseng.com/interns?keyword=<关键词>&type=school`
（`type=school` = 校招；实习可去掉）

- 卡片：`.intern-item`，实测 20 个/页，**免登录可抓**
- 详情直链：`https://www.shixiseng.com/intern/inn_<id>` —— `inn_xxx` 即天然主键
- 卡片自带「应届生 / 本科」标签，校招场景信息密度高
- 详情页 JD **免登录可读**，实测切出 206 字
- **投递按钮免登录就渲染**：选择器 `.resume_apply`（`.btn-box.resume_apply.com_res`），
  文案「**投个简历**」，实测 131×61 可见
- 实测点击 → 弹出 `.footer-login--is-show`（短信登录 / 密码登录 / 微博 / QQ）→ **登录墙，未投递**

判定：**登录后能完成投递**，且是这批平台里链路最干净的一个。

抓取 JS 见 [js-snippets.md](js-snippets.md)「抓取-实习僧卡片」。

## 前程无忧 51job

搜索 URL：`https://we.51job.com/pc/search?keyword=<关键词>&searchType=2&jobArea=<城市码>`

- 卡片：`.joblist-item`，实测 20 个/页，**免登录可抓**
- 详情直链：`https://jobs.51job.com/all/co<随机串>.html`
- 卡片里有「投递」按钮（列表页直接投）
- **详情页会撞滑块**：访问详情页返回「滑动验证页面 / 请按住滑块，拖动到最右边」

判定：**只能抓列表**。要投递必须人工过一次滑块，自动化不稳定，不建议放进批量链路。
校招频道是 `https://xy.51job.com/`，同样受滑块限制。

## BOSS 直聘 / 猎聘（不可用）

两者表现一致：`navigate_page` 返回成功（标题正常），但紧接着 `evaluate_script` 时
`location.href` 已变成 `about:blank`，页面被清空。

判定：**反爬主动踢出自动化会话**，不要用 chrome-devtools 直接打这两个站。
如果一定要做，只能走用户日常浏览器 + 纯人工节奏（bsk 也可能同样被识别）。

## 给新平台做适配的最短路径

1. 打开搜索页 → `evaluate_script` 数几个候选选择器的元素个数，找到卡片容器
2. 从卡片里找 `a[href]`，确认有稳定的详情直链（能当主键）
3. 打开一个详情页 → 按 `js-snippets` 的「JD门禁」切正文，确认切得出来
4. 找投递按钮：先 `querySelectorAll('button')`，没有就搜含「投递 / 申请 / 简历」的任意元素
   （实习僧的按钮就是个 div，不是 button）
5. 点一下看弹什么：登录框 = 需登录；简历选择弹窗 = 链路通

任何一步撞上滑块 / about:blank / 验证码 → 该平台判为不可用，换下一个。

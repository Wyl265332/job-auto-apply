# job-auto-apply

一句话「帮我投递简历」，AI 助手帮你把**抓岗位 → 按简历筛选 → 投递 → 出报告**跑完。

一个给 AI Agent 用的 Skill（不是独立软件）。它不夹带任何个人数据，
身份、简历、偏好全部走你自己填的 `config.json` + `resume_profile.json`。

---

## 它能干什么

| 环节 | 说明 |
|---|---|
| 抓岗位 | 按关键词批量抓搜索页，从框架实例里掏出岗位主键与详情直链 |
| **按简历筛选** | 每条 JD 都拿你的简历画像过一遍，不达标**不投** |
| 试投确认 | 先试投 3 条，**在最终确认前停手**，等你点头才放量 |
| 自动落盘 | JD、投递日志、报告按 `日期/平台/岗位` 自动归档 |
| 出报告 | 本轮明细 + 累计总报告（幂等）+ JD 关键词总结 |

## 快速开始

### 1. 装驱动（选一个）

**chrome-devtools MCP（推荐）** —— 定位稳、没有后台进程烦恼

```bash
npx -y chrome-devtools-mcp@latest --no-usage-statistics
```

把配置加进你的 MCP 配置文件（详见 `mcp/README.md`）。

**bsk（备用）** —— 连你日常那个已登录的浏览器，天然带登录态。
`with-drivers` 包里带了 `bsk.exe`，放进 PATH 即可；另外需要在浏览器里装它的扩展。

### 2. 初始化

```bash
python scripts/setup.py --driver chrome-devtools --root ~/Documents/投递记录
python scripts/workflow.py init --root ~/Documents/投递记录
python scripts/workflow.py doctor          # 全绿才算装好
```

### 3. 填两份配置

- `config.json` —— 关键词、黑名单、平台 URL、驱动
- `resume_profile.json` —— **简历画像**，防误投的核心

**不填 `resume_profile.json` 就等于裸投**，doctor 会报警。

### 4. 让 AI 助手跑

> 帮我在实习僧投运营方向的校招岗位

它会：体检 → 抓 → 逐条筛选 → 试投 3 条停手汇报 → 你点头 → 放量 → 出报告。

## 目录结构（自动建）

```
投递记录/
├── jd/<日期>/<平台>/<pk>.json     岗位 + JD + 筛选结果
│              └─ <pk>.md        人能读的版本
├── logs/<日期>-<平台>.jsonl       逐条投递日志（可断点续跑）
│     投递汇总-<日期>-<平台>.md    本轮报告
├── raw/raw-<日期>-<平台>.json     抓取去重后的卡片
├── 投递汇总报告.md                 总报告（幂等累加）
└── 已查看岗位JD关键词总结.md
```

## 防误投怎么做的

`scripts/workflow.py screen` 每条都按这个顺序判，负向永远优先于正向：

```
否决词 → 校招/届别 → 工作经验负向 → 学历 → 专业 → 城市 → 薪资下限 → 能力词加分 → 选简历
```

实测样例：

| 岗位 | 判定 |
|---|---|
| 2027届校招 + 本科 + 专业不限 + 文案岗 | 放行，选内容简历 |
| 要求 3 年以上相关经验 | 拦截 |
| 大专以上学历 | 拦截 |
| 城市不在列表 | 拦截 |
| 电话销售 / 地推 | 拦截（否决词）|
| 行政岗（考勤/档案/会务）| 放行，选行政简历 |
| 薪资低于下限 | 拦截 |

## 红线

- 遇验证码 / 登录失效 → **立即停止**，不重试、不绕过
- 不过筛选就**不许投**
- 不碰凭据：不导 cookie、不填密码、不做免登，登录只由你手动完成
- 不编造简历内容
- 每条之间 sleep，不并发轰炸

## 发布到 GitHub 之前

1. **选一个许可证**：仓库里放了 `LICENSE-MIT.template`，改名为 `LICENSE` 即可；
   不同意 MIT 就换成你自己的。没有许可证的公开仓库默认是"保留所有权利"，别人不能用。
2. **确认没有个人信息**：`grep -r "你的名字\|你的学校\|你的电话" .` 跑一遍。
3. **不要提交** `config.json`、`resume_profile.json`、`投递记录/`
   —— 根目录的 `.gitignore` 已经把它们排除了。
